# XA-3008: Vacuity court: acceptance that passes on the unmodified base is vacuous

- **Standing**: UNKNOWN

## Status
UNKNOWN
- **Repository**: seanchatmangpt/xaas @ `d478a63`

## Description
Innovation adoption (item 2; DfCM composition C05). New lib/xaas/sjira/vacuity_court.ex modelled on Xaas.Ultracode.SubstitutionCourt (lib/xaas/ultracode/substitution_court.ex qualify/3 returning receipt or typed refusal): given an order's acceptance commands and base checkout, run them (argv lists, never shell strings) on the unmodified base; if all pass the order is VACUOUS and the court refuses. Hook into Xaas.Sjira.ArdCourt without altering its current verdicts for non-vacuous orders. Do the static/base-run lens only; the revert-mutation lens is out of scope.
