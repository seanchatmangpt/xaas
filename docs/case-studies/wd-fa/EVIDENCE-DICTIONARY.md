# Evidence Dictionary

| Term | Meaning |
|---|---|
| observed evidence | directly obtained from a bound source |
| derived evidence | deterministic/declared transformation of observed evidence |
| candidate | proposed interpretation with no authority |
| applicability | conditions under which prior knowledge may govern this subject |
| required evidence | evidence needed before a rule can be admitted |
| falsifier | observation that rejects/narrows a candidate |
| confidence basis | explanation of why a standing is assigned |
| receipt | durable binding of subject, evidence, verifier and outcome |
| replay identity | stable identity used to reproduce verification |
| evidence ceiling | strongest standing supported by available evidence |
| MachineExperience | verified, applicability-bounded reusable prior art |
