# Case Capability Selection

The running demo selects an explicit bounded capability set for each case.

Friday capabilities are limited to OBSERVE / SELECT / CONSTRUCT.

```
reconstruct_subject
retrieve_prior_cases
rank_hypotheses
test_applicability
construct_diagnostic_work
project_sjira
project_view
```

The production DO capability remains outside the Friday admissible set and is surfaced separately in the STOGAF JSON projection.
