# MachineExperience

MachineExperience is not "memory" and not an automatically appended vector-store document.

It is reusable organizational prior art admitted only after verified consequence.

## Admission equation

```
MachineExperience =
  VerifiedConsequence
  + Provenance
  + Applicability
  + EvidenceCeiling
  + ReplayIdentity
```

## Required fields

A MachineExperience SHOULD bind:

- source failure case;
- observed symptom;
- exact subject population;
- evidence set and digests;
- candidate history;
- engineer disposition;
- verifier;
- diagnostic/corrective procedure;
- outcome;
- applicability conditions;
- falsifiers;
- evidence ceiling;
- receipt;
- replay identity;
- policy/standard version.

## Lawful transition

```
UNKNOWN
→ candidate
→ investigation
→ engineer disposition
→ independent verification
→ receipt
→ MachineExperience
→ future replay
```

## Negative controls

The system MUST reject:

- self-certified receipts;
- tampered receipts;
- disposition mismatch;
- population/applicability mismatch;
- missing verifier;
- missing replay identity;
- candidate-only evidence.

## Standard improvement

Verified experience MAY:

- create a new failure-mode rule;
- narrow an existing applicability condition;
- add a falsifier;
- add required evidence;
- change diagnostic work;
- supersede prior standard work.

It MUST NOT silently universalize a local observation.
