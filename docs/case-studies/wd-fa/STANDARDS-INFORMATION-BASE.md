# Standards Information Base

The architecture should reuse existing standards where they fit.

| Standard / vocabulary | Use in WD CS2 |
|---|---|
| RDF/RDFS/OWL | canonical semantic representation |
| SHACL | executable structural constraints |
| SPARQL | query, gate and projection |
| PROV-O | provenance and derivation |
| W3C ORG | organizational roles/structures where needed |
| SKOS | controlled concepts / standing labels |
| OWL-Time | temporal identities where needed |
| SOSA/SSN | observations/sensors where appropriate |
| QUDT | typed engineering quantities where appropriate |
| OCEL 2.0 | object-centric event/process evidence |
| OpenAPI / JSON Schema | generated API interface projection |

Use WD-local vocabulary only where the public semantics are insufficient.
