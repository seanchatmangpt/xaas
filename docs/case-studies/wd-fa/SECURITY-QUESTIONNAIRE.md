# Security / Governance Questionnaire

- Which source classifications exist?
- Is access inherited from source ACLs or centrally governed?
- Are row/object-level restrictions required?
- Can derived evidence expose sensitive source content?
- Which models/runtimes are approved for which classifications?
- Are prompts/outputs retained by providers?
- Is customer/employee PII present in FA material?
- Which actions require dual control?
- Which evidence must be immutable?
- What audit events must be retained?
- Which dispositions have regulatory/customer consequences?
- What is the policy for conflicting evidence?
- Who may admit, supersede or revoke MachineExperience?
- What is the emergency disable/rollback mechanism?
