# Pilot Exit Criteria

Expansion beyond the bounded pilot requires measured evidence.

## Trust

- false-KNOWN below agreed threshold;
- no unresolved critical provenance defect;
- engineers can trace recommendations to exact evidence;
- authorization/ACL tests pass.

## Utility

- target prior-art retrieval performance met;
- diagnostic-action usefulness meets agreed threshold;
- measurable reduction in context reconstruction or exploratory work;
- acceptable engineer override pattern.

## Operations

- runbooks exercised;
- support ownership accepted;
- source connector health observable;
- replay/receipt path works;
- rollback/disable path tested.

## Governance

- production authority policy explicitly approved;
- retained audit data agreed;
- MachineExperience admission/revocation policy owned.

Failure of exit criteria means hold, narrow or stop—not automatic rollout.
