# STOGAF Architecture Receipt

The exact-head court emits `wd-cs2-stogaf-receipt.json`.

The receipt binds:

- exact git subject SHA;
- current and target STOGAF conformance;
- evidence ceiling;
- authority and human gate;
- requirement/viewpoint/work-order counts;
- Friday capability count;
- explicit absence of Friday DO capability;
- count of unclaimed production conformance levels;
- known-path LLM policy.

The receipt is deliberately an **architecture evidence receipt**. It does not assert deployment, customer acceptance, production consequence, MTTR improvement or external standing.
