The submission is Level-10-ready when the case study, code, semantic graph, work, views and evidence are projections of the same exact subject.

```

→ requirements graph
→ STOGAF architecture episode
→ canonical WD state
```

## Must be observable

- KNOWN positive case;
- PARTIAL missing-evidence case;
- UNKNOWN novel case;
- misleading-similarity negative control;
- candidate score cannot create KNOWN;
- engineer disposition boundary;
- verified MachineExperience replay;
- STOGAF current/target standing;
- explicit non-claims.

## ST-6 acceptance

ST-6 AUTONOMIC is earned only when admitted architecture state can select and construct the required work/view/application projections and verification path without a human reconstructing semantic context.

This remains repository-local standing.

## Not required for Friday

- real WD production data;
- live production source connectors;
- production DO authority;
- measured production MTTR improvement;
- ST-7/8/9.

Those belong to the proposed 30/60/90.
