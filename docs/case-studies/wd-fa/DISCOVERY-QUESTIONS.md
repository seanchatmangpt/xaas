# Discovery Questions for WD

## Failure-analysis process

- How is a failed drive/case created and identified today?
- Which dispositions are authoritative?
- What makes a prior case "applicable" rather than merely similar?
- Which evidence is mandatory for common failure families?
- Which tests are scarce, destructive or slow?
- What is the escalation path for novel cases?

## Data

- What are the authoritative identifiers for drive, serial, build, lot, supplier, BOM, firmware and station?
- Where do FA reports, plots, images and work notes live?
- Which sources have durable APIs?
- What lineage is already available?
- How often do schemas/identifiers change?

## Evaluation

- How is root-cause ground truth established?
- What historical cases are sufficiently complete for replay?
- What false-known rate would be unacceptable?
- What is current median/p95 time to disposition by case type?

## Governance

- Which data may be sent to which model/runtime?
- What source ACLs must propagate?
- Which actions require explicit engineer approval?
- What retention/audit obligations apply?
