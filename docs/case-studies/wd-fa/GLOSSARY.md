# Glossary

**ALIVE** — exact subject observed passing its required court within the stated evidence ceiling.

**PARTIAL_ALIVE** — meaningful evidence exists, but at least one required proof remains incomplete.

**UNKNOWN** — standing is not established.

**KNOWN** — deterministic applicability/evidence conditions admit a known failure mode for the exact subject.

**PARTIAL** — known applicability is plausible but required evidence is incomplete/conflicting.

**CandidateHypothesis** — ranked proposal; never authority by itself.

**O*** — admitted canonical enterprise/architecture state.

**μ** — lawful manufacture from canonical state to an artifact/projection.

**sJira** — semantic work/evidence projection.

**SA2A** — semantic typed capability interaction.

**BRCE** — authority/consequence boundary preserving SELECT ≠ CONSTRUCT ≠ DO.

**Chicago court** — verification with real owned collaborators rather than mocks.

**STOGAF** — Semantic TOGAF, a TOGAF-compatible semantic execution profile; not an official Open Group specification.
