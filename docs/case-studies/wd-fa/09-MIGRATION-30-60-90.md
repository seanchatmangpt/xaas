# 30 / 60 / 90 Migration Plan

## Days 0–30 — bounded vertical slice

Goal: prove semantic joining, trust mechanics and operator usefulness.

Deliver:

- source inventory and access map;
- one bounded product/failure domain;
- historical case sample;
- structured build-provenance join;
- representative multimodal artifacts;
- KNOWN/PARTIAL/UNKNOWN admission;
- FA Morning Brief;
- audit/provenance;
- shadow-only recommendations.

Exit criteria:

- false-KNOWN negative controls pass;
- engineers can trace every recommendation;
- missing evidence is visible;
- no production consequence is automatic.

## Days 31–60 — real-source shadow

Goal: compare system output with existing FA process.

Deliver:

- authorized real-source connectors;
- source ACL propagation;
- expanded prior-art corpus;
- disposition capture;
- sJira work projection;
- evaluation dashboard;
- replay/receipt flow;
- incident and support runbooks.

Exit criteria:

- acceptable retrieval/applicability performance;
- stable source lineage;
- identified failure modes and operating gaps;
- no unresolved critical governance issue.

## Days 61–90 — bounded pilot

Goal: measure operational value without expanding authority prematurely.

Deliver:

- selected production-adjacent cohort;
- explicit operator roles;
- bounded human-gated workflow;
- MachineExperience admission after verified disposition;
- observed process deltas;
- pilot outcome review.

Exit criteria:

- measurable reduction in repeated exploratory work;
- acceptable false-KNOWN/false-UNKNOWN guardrails;
- operational owner accepts handoff;
- decision whether to expand, modify or stop.
