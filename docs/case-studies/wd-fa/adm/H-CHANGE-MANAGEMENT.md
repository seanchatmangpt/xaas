# Phase H — Architecture Change Management

## Change trigger

Verified new experience may reveal:

- a new FailureMode;
- narrower applicability;
- a new falsifier;
- new required evidence;
- better diagnostic sequence;
- obsolete standard work;
- new source/capability requirement.

## Admission

Architecture change is not triggered by an LLM suggestion alone.

```
observed novelty
→ candidate change
→ evidence
→ verification
→ policy/authority
→ admitted semantic change
→ regenerated projections
→ regression court
```

## WD fixture

The repository-local `novel_x` flow demonstrates the mechanics of UNKNOWN → verified experience → future KNOWN, but does not prove production organizational learning.
