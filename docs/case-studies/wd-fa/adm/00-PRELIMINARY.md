# Preliminary — Architecture Capability and Governance

## Purpose

Establish the vocabulary, principles, evidence ceilings, authority boundaries and conformance model before solution choices are made.

## WD CS2 decisions

- Canonical state is semantic and object-centric.
- `A = μ(O*)`.
- STOGAF is TOGAF-compatible but not an official Open Group specification.
- Friday evidence ceiling is `REPO_LOCAL_FIXTURE`.
- Friday authority is `SELECT_CONSTRUCT_ONLY`.
- Consequential FA disposition requires `ENGINEER_DISPOSITION_REQUIRED`.
- Public vocabularies are reused where semantics fit.
- UNKNOWN is a lawful result.
- No architecture claim is promoted solely by model confidence.

## Exit condition

Architecture principles, conformance ladder, semantic vocabulary and authority model are explicit and testable.
