# Phase C — Application Architecture

## Existing-system posture

The proposal does not require replacing WD systems of record.

Adapters project source state into a canonical semantic subject.

- identity resolver;
- prior-art retrieval;
- candidate ranker;
- deterministic admission;
- work constructor;
- sJira projector;
- SA2A capability router;
- operator/manager/executive view projector;

- MachineExperience compiler.
