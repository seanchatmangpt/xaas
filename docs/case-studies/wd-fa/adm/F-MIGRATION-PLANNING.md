# Phase F — Migration Planning

Migration follows evidence, not feature count.

## Plateau 1 — repository proof

Synthetic/representative data, deterministic courts, bounded views and no production authority.

## Plateau 2 — real-source shadow

Authorized source connectors, ACL preservation, historical replay, engineer comparison and process measurement.

## Plateau 3 — bounded pilot

Human-gated production-adjacent workflow with verified disposition capture and MachineExperience admission.

## Plateau 4 — policy expansion

Only if measured evidence supports it, selected reversible/known operations may receive bounded pre-authorized consequence.

No plateau is promoted because the previous one "looks good" in a demo. Exit criteria require observed evidence.
