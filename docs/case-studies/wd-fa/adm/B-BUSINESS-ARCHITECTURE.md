# Phase B — Business Architecture

## Baseline process

```
symptom
→ engineer gathers reports and build history
→ reconstructs context
→ searches prior work
→ chooses tests
→ reaches disposition
→ result is partially trapped in local artifacts
```

## Target process

```
symptom
→ subject reconstructed automatically
→ evidence/prior art joined
→ candidates ranked
→ applicability/evidence admitted
→ work constructed
→ engineer handles consequential judgment
→ outcome verified
→ reusable prior art admitted
```

## Business capability changes

| Capability | Baseline | Target |
|---|---|---|
| context reconstruction | manual | deterministic projection |
| prior-case search | fragmented | evidence-bound retrieval |
| known/novel decision | implicit | explicit standing |
| work routing | prose/ticket dependent | semantic obligation |
| learning | document accumulation | verified MachineExperience |
| management visibility | retrospective reporting | live viewpoint projection |
