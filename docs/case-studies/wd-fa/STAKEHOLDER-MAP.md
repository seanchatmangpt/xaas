# Stakeholder Map

| Stakeholder | Concern | Primary view | Decision / authority |
|---|---|---|---|
| FA engineer | correct next action and evidence | Morning Brief / case detail | disposition |
| FA manager | queue health, recurrence, blockers | operating board | prioritization/escalation |
| firmware team | applicable firmware failures | domain work view | firmware corrective action |
| supplier quality | supplier/lot evidence | supplier work view | supplier corrective process |
| data/platform | connectors and lineage | architecture/operations | platform operations |
| security | source access and disclosure | governance view | policy/authorization |
| leadership | value, risk, adoption | board deck | pilot/scale decision |
| FDE | integration and manufacture | architecture/evidence | construct, not permanent ownership |

The FDE is intentionally absent from the terminal operating dependency graph.
