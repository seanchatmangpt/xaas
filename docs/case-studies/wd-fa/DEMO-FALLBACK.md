# Demo Fallback Plan

The live demo has four fallback levels.

## Level 0 — live served browser

Use the Phoenix WD surface and execute KNOWN → PARTIAL → UNKNOWN → MachineExperience replay → STOGAF.

## Level 1 — local exact-head court

Run the dedicated tests and print the STOGAF receipt.

## Level 2 — hosted CI evidence

Open the exact-head workflow run and artifact receipt.

## Level 3 — static architecture walk-through

Use the deck plus:

- requirement traceability;
- C4/Mermaid;
- conformance report;
- receipt schema;
- explicit non-claims.

The fallback never replaces missing runtime evidence with a claim that the runtime succeeded.
