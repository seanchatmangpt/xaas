# FDE Handoff Runbook

Handoff is a demonstrated operational capability, not delivery of documents.

## Recipient must be able to

- identify canonical semantic state;
- trace a view to its source subject;
- run the repository courts;
- reconstruct a failed fixture;
- understand authority boundaries;
- add a new prior case without inventing a parallel model;
- inspect sJira work;
- inspect SA2A capabilities;
- verify a receipt;
- understand how MachineExperience is admitted/refused.

## Ownership

The target operating model assigns source adapters to source-owning teams, FA semantics to FA/domain owners, platform runtime to platform engineering, policy to governance/security and disposition policy to engineering leadership.

The FDE should not remain the only person who knows how these pieces connect.
