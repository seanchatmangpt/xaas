## Charter: RCA on cycle 0538's real hang, then retry its goal with the fix applied

**Real incident**: `vision-2030-cycle-2026-09-09-0538` (building `mix
xaas.workflow.verify_and_commit`) never completed. Checked at ~2 hours elapsed: zero
live `beam.smp`/`mix` process, no commit, no task-notification. Stopped via
`TaskStop` this cycle after confirming it was dead, not merely slow.

**Real root cause, found by reading its journal.jsonl directly**: the `LoopUntilDry`
phase reached **round 937+** before being killed. My own workflow script's
loop-until-dry pattern was:
```js
while (dry < 2) {
  const round = await agent(`Find any NEW real edge case... If nothing new, say so.`)
  const fresh = round.new_findings.filter(f => !seen.has(f.title))
  if (!fresh.length) { dry++; continue }
  dry = 0
  ...
}
```
This is safe for an *enumerable* real search (e.g. "find every real occurrence of bug
pattern X in this codebase" — finite, converges when the codebase is exhausted). It
is **not safe** for an *open-ended design* question ("find a new edge case for a mix
task that doesn't exist yet") — an LLM asked to invent an edge case will always
produce *a* plausible-sounding one, so the two-consecutive-empty-rounds exit
condition can run indefinitely. Every prior cycle this session that used
loop-until-dry happened to converge quickly by luck (the search spaces were smaller/
more bounded); this is the first time the pattern was applied to a design-brainstorm
question, and it never terminated.
